# Core transport authentication

## Current adapter

The transitional Bearer adapter accepts high-entropy opaque credentials and stores only their SHA-256 digests in process memory. Each digest is configured with one server-owned subject and a fixed role set. Request JSON cannot provide or override identity or roles.

Credential records are supplied programmatically to Core. This repository contains no production values, digest registry or credential file format. A production bootstrap mechanism will be designed with OpenBao rather than inferred here.

Bearer-token credentials must:

- be generated by a cryptographically secure random source with at least 256 bits of entropy;
- never be human passwords or reusable provider credentials;
- be transmitted only over TLS;
- be independently scoped, rotated and revocable;
- remain outside prompts, model context, URLs, logs, traces and error output.

The SHA-256 comparison is constant-time and all configured records are checked. Weak credentials remain vulnerable to offline guessing if a digest is disclosed, so digest configuration is sensitive and requires restricted filesystem/process access.

## Network boundary

Core can bind only to:

- loopback;
- RFC1918 IPv4 private addresses;
- IPv6 unique-local addresses.

Unspecified, multicast and public addresses are rejected by the listener constructor. Normal deployment will bind to loopback or a private service address and receive HTTPS traffic through the internal Nginx gateway.

Nginx must not manufacture identity/role headers. It forwards the opaque authorization credential without logging it. Trusted proxy behavior, certificate validation and rate limits require explicit configuration review before deployment.

## Target identity

Bearer-token authentication is a bootstrap adapter, not the final identity architecture. Prefer mTLS or workload identity for privileged service-to-service communication and short-lived credentials brokered through OpenBao. Migration must preserve the same server-owned Principal and role boundary.
